# Exploratory Data Analysis

This folder contains exploratory analysis work for the auction dataset. This is separate from the main codebase and should not affect production code.

## Contents

- `auction_eda.ipynb` - Main exploratory data analysis notebook
- `summary.md` - Summary of findings and feature engineering recommendations
- `figures/` - Generated visualizations

## Purpose

Perform exploratory analysis to support future feature engineering work with the auction dataset for predicting item prices.
